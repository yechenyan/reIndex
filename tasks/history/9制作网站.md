## 实际交付

- 在 `packages/web-app` 新增 React Web 应用，保持页面和主要组件在 200 行以内。
- `#/explore` 提供 Collection/Node 树与右侧 Node 详情，支持数据卡、内容预览和资源查看。
- `#/search` 作为独立搜索页，支持 lexical、semantic、hybrid、Node 类型筛选、分页和跳回 Explore。
- Markdown 数据卡支持 GFM 表格；搜索返回的 `table_row` 按字段和值格式化，已提交查询的关键词在标题、正文和表格中高亮。
- 新增 `GET /v1/collections` 和 `POST /v1/nodes/browse` 作为前端浏览接口；Node 详情和搜索继续复用现有
  `POST /v1/get` 与 `POST /v1/search`。
- Qwen embeddings 默认启用，MiniLM reranker 默认关闭；`scripts/dev.py` 可一键启动 ParadeDB、API 和 Vite，
  已安装的依赖不会重复同步。

## 范围调整与决策
