## 决策与实施记录

- 权威契约位于 `packages/server/src/reindex_server/openapi/reindex-http-v1.yaml`，并作为
  `reindex-server` package data 发布；运行时 `/openapi.json` 直接读取该契约。
- `scripts/check_http_contract.py` 不读取运行时缓存，而是从注册的 FastAPI routes 重新生成实现 Schema，
  与权威契约做完整结构比较。开发顺序因此固定为先改契约、再改实现、最后通过一致性检查。
- 为避免破坏现有 Pydantic 跨字段 validator 和业务语义，本阶段不以生成模型替换现有运行时模型；现有模型
  作为 HTTP adapter 实现并由完整 Schema 比较约束。后续若生成 SDK 或只读数据模型，应仍以权威 YAML
  为输入，不能反向覆盖契约。
- `/v1/pull` 和 `/v1/get` 只修正 OpenAPI 中的 binary media type 与响应头描述；handler、参数和实际返回
  对象未改变。
- `/docs` 改用 Scalar，关闭 Agent、proxy、telemetry 和 developer tools；Scalar JS 固定为 1.63.0。
  根据审核前追加请求，不再保留 `/docs/swagger` 与 `/docs/oauth2-redirect`；回归测试固定两者返回 404。
- HTTP 接口按 System、Collections、Versions、Resources、Search 分组。operation ID、请求字段、默认值、
  响应模型和错误结构保持现状。
- 新增 `scalar-fastapi>=1.8,<2` 运行依赖；wheel 已验证包含权威 YAML 与该依赖元数据。
- 根目录 `AGENTS.md` 现在将 HTTP OpenAPI 文件声明为 wire contract 的权威来源，规定契约、实现、文档的
  修改顺序，并强制每次 HTTP 变更运行完整契约比较和相关测试。
- 根目录 `AGENTS.md` 现在要求 AI 新建或实质修改的手写源码与文档默认不超过 200 行；特殊情况必须在
  活跃任务说明理由且绝不能超过 300 行。超限必须按职责拆分，禁止删逻辑、压缩格式或隐藏代码规避。
