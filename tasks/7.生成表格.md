## 实验决策

- 不采用“候选优先”和全文档多框架候选并集。
- 采用“原始页面视觉发现 -> 独立完整性审核 -> 冻结清单 -> 已接受 bbox 内的 PyMuPDF 后验提取 -> 盲审 QA”。
- Docling 只在无可用文本层或 PyMuPDF 定向提取失败时作为备选，不在发现阶段全文运行。
- 源文保真表和 ReIndex 规范化表分两阶段验证，避免把标题缩写、货币格式和行排序差异误判成提取错误。
- 三组最终清单均命中 18 个逻辑表和 27 个物理段；三组 Bielefeld 源文保真结果均为 24/24 条汇总记录语义一致、52×20 明细数据单元格全量一致。差异在发现阶段的噪音、锚定风险和额外成本，而不是最终可达到的上限精度。

下一步为按该决策实现 ReIndex Agent skill、中性 PDF 证据工具、定向提取和 QA；任务尚未进入人工完成审批。

## 提取策略自由度调整（2026-08-02）

- 明确 package 只标准化证据、运行接口、溯源和验证，不规定统一提取算法。
- Agent Skill 增加逐表策略选择：固定网格、锚点/聚类、矢量线重建、状态机、后验原生候选、局部 OCR 或直接专用代码均可混用。
- 固定行带和列边界降级为可选策略；只有真实共享版式时才复用辅助函数。
- QA 除行列数外，要求加入表级锚点、关键列、跨页边界或坐标漂移断言，降低模板误用导致的静默错误。
