# ReIndex theme

Static product index page, design guidelines, a custom ReIndex logo, and reusable design tokens for ReIndex.

## Brand basis

This theme follows the Reiner Lemoine Institut corporate-design manual:

- Primary blue: `#002E4F`
- Primary grey: `#A5A6A6`
- Accent green: `#00E47C`
- Typeface: Nunito Sans

Open `index.html` for the product page, `guidelines.html` for the design guidelines, or `logo-options.html` to compare four logo directions. The hero illustration lives at `assets/reindex-indexing-illustration.png`. Reusable custom properties are defined at the top of `theme.css`.
