# reindex-web-app

React frontend for browsing and searching active ReIndex Collections.

## Pages

- `#/explore`: Collection and Node tree with card, content, and resource views.
- `#/search`: lexical, semantic, or hybrid Evidence search scoped to one Collection.
- `#/doc`: parent entry for protocol documentation.
- `#/doc/cli`: CLI reference generated from the `reindex/cli@1.0` contract.
- `#/doc/api`: Scalar reference rendered from the HTTP OpenAPI contract.

The CLI page reads `public/doc/cli-v1.json`, generated by
`scripts/compile_cli_contract.py`; do not edit that artifact by hand.

## Development

From the repository root, start ParadeDB, the embedding-enabled API, and this
web app together:

```bash
./scripts/dev.py
```

The first run opens Docker Desktop when needed, creates the persistent local
ParadeDB container, initializes the schema, and downloads the Qwen embedding
model. The launcher only installs Python or web dependencies when its checks
find them missing. Later runs reuse dependencies, the database volume, and the
model cache.
